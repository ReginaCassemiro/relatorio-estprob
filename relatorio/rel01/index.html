1 📌 Introdução

O R é uma linguagem de programação gratuita e de código aberto, desenvolvida especialmente para análise estatística e visualização de dados. Surgiu como uma implementação da linguagem S e hoje é amplamente utilizada por pesquisadores, cientistas de dados e engenheiros ao redor do mundo.

Uma das grandes vantagens do R é sua capacidade de realizar desde operações matemáticas simples até análises estatísticas complexas, tudo dentro de um ambiente interativo chamado RStudio. Nele, é possível escrever scripts, visualizar gráficos, gerenciar arquivos e organizar projetos de forma prática.

Nesta prática, foram estudados os fundamentos da linguagem R com base no curso R Básico 2024, explorando os principais conceitos necessários para iniciar o uso da linguagem no contexto acadêmico e científico.

3 📚 Fundamentação Teórica

O R trabalha com o conceito de que tudo é um objeto. Um objeto pode ser um número, um vetor, uma matriz, uma lista ou um conjunto de dados (data frame). A criação de objetos é feita pelo operador de atribuição <-, como no exemplo:

Código 
x <- 10
x
[1] 10

Os principais tipos de dados no R são:

  • Numérico (numeric): valores decimais, como 3.14
  • Inteiro (integer): números inteiros, como 5L
  • Caractere (character): texto, como "Regina"
  • Lógico (logical): valores TRUE ou FALSE

As funções são chamadas pelo nome seguido de parênteses. Por exemplo, mean() calcula a média de um vetor, sum() calcula a soma e length() retorna o número de elementos.

5 🔍 Resultados e Discussão

Durante o estudo, foram praticados os principais comandos da linguagem R. A seguir estão alguns exemplos das operações realizadas:

5.1 📊 Análise de Dados

Código 
# Criando um vetor com valores numéricos
valores <- c(5, 10, 15, 20, 25)

# Calculando estatísticas básicas
media <- mean(valores)
desvio <- sd(valores)
soma <- sum(valores)

cat("Média:", media, "\n")
Média: 15
Código 
cat("Desvio padrão:", desvio, "\n")
Desvio padrão: 7.905694
Código 
cat("Soma:", soma, "\n")
Soma: 75
Código 
# Tipos de objetos no R
nome <- "Regina"
idade <- 21
aprovada <- TRUE

class(nome)
[1] "character"
Código 
class(idade)
[1] "numeric"
Código 
class(aprovada)
[1] "logical"

Os resultados mostram que o R permite trabalhar com diferentes tipos de dados de forma simples e direta. A função class() identifica o tipo de cada objeto, o que é fundamental para entender como o R processa as informações.

Observou-se que a linguagem possui uma sintaxe clara e intuitiva, facilitando o aprendizado para iniciantes. As funções básicas como mean(), sum() e sd() são suficientes para realizar as primeiras análises estatísticas.
