1 📌 Introdução

O desenvolvimento de pacotes é uma das formas mais eficientes de organizar, documentar e compartilhar funções em R. Um pacote permite que um conjunto de funções seja reutilizado em diferentes projetos, com documentação padronizada e controle de versão (Batista e Oliveira, 2022).

Neste relatório, é descrito o desenvolvimento do pacote converteR, criado para realizar conversões de unidades de medida nas categorias de distância, massa, temperatura e volume. O pacote foi desenvolvido com o auxílio do pacote devtools e documentado com o padrão Roxygen2. O código-fonte está disponível no repositório: https://github.com/ReginaCassemiro/converteR.

2 🎯 Objetivos

2.1 Objetivo geral

Desenvolver um pacote R para conversão de unidades de medida, documentando as funções exportadas e disponibilizando o projeto no GitHub.

2.2 Objetivos específicos

  • Criar a estrutura do pacote com devtools
  • Desenvolver e documentar as funções de conversão com Roxygen2
  • Preencher o arquivo DESCRIPTION com as informações do pacote
  • Instalar e testar o pacote localmente
  • Enviar o projeto ao GitHub

3 📚 Fundamentação Teórica

Um pacote R é composto por uma estrutura de pastas e arquivos padronizada. Os principais componentes são (Batista e Oliveira, 2022):

  • R/: pasta onde ficam os arquivos com as funções do pacote
  • DESCRIPTION: arquivo com metadados do pacote (nome, versão, autor, descrição, licença)
  • NAMESPACE: arquivo que controla quais funções são exportadas e importadas
  • man/: pasta gerada automaticamente com a documentação das funções em formato .Rd

O pacote devtools facilita o desenvolvimento, fornecendo funções como create() para criar a estrutura, document() para gerar a documentação e install() para instalar o pacote localmente (Wickham et al., 2022).

A documentação das funções é escrita com o padrão Roxygen2, utilizando comentários especiais que começam com #'. As principais tags são:

  • @param: descreve um parâmetro da função
  • @return: descreve o valor retornado
  • @export: indica que a função será exportada
  • @examples: fornece exemplos de uso

4.1 Passo 1 — Criação da estrutura do pacote

O pacote foi criado com a função devtools::create(), que gera automaticamente a estrutura de pastas e arquivos necessários:

Código 
library(devtools)
devtools::create("converteR")

A estrutura gerada foi:

converteR/
├── R/
├── DESCRIPTION
├── NAMESPACE
└── converteR.Rproj

4.3 Passo 3 — Desenvolvimento das funções

As funções foram desenvolvidas no arquivo R/conversoes.R, utilizando a documentação Roxygen2. O pacote contém 7 funções de conversão:

Função Conversão
km_para_m() Quilômetros → Metros
m_para_km() Metros → Quilômetros
kg_para_g() Quilogramas → Gramas
g_para_kg() Gramas → Quilogramas
celsius_para_fahrenheit() Celsius → Fahrenheit
fahrenheit_para_celsius() Fahrenheit → Celsius
litros_para_ml() Litros → Mililitros

Exemplo da documentação Roxygen2 para a função km_para_m():

Código 
#' Converte quilometros para metros
#'
#' @param km Valor em quilometros
#' @return Valor em metros
#' @export
#' @examples
#' km_para_m(5)
km_para_m <- function(km) {
  km * 1000
}

6 🧠 Considerações finais

O desenvolvimento do pacote converteR permitiu compreender na prática o processo de criação, documentação e distribuição de pacotes em R. O uso do devtools simplificou cada etapa do processo, desde a criação da estrutura até a instalação local.

A documentação com Roxygen2 garante que cada função tenha sua descrição, parâmetros e exemplos de uso registrados de forma padronizada, facilitando o uso por outros usuários.

O pacote está disponível publicamente no GitHub e pode ser instalado diretamente com:

Código 
devtools::install_github("ReginaCassemiro/converteR")
