3 📚 Fundamentação Teórica

No R, todos os dados são armazenados em objetos. Os dois tipos mais utilizados nesta aula são (Batista e Oliveira, 2022):

  • Vetor: estrutura unidimensional que armazena elementos do mesmo tipo
  • Data frame: estrutura tabular onde cada coluna pode ter um tipo diferente, semelhante a uma planilha

3.1 Vetores

A função c() concatena elementos para formar um vetor. A função names() atribui nomes a cada posição do vetor, permitindo indexação por nome além de indexação numérica:

Código 
notas <- c(7.5, 8.0, 6.5, 9.0, 5.5)
alunos <- c("Ana", "Bruno", "Carlos", "Daniela", "Eduardo")
names(notas) <- alunos
notas
    Ana   Bruno  Carlos Daniela Eduardo 
    7.5     8.0     6.5     9.0     5.5

A indexação lógica permite selecionar elementos com base em condições:

Código 
aprovados <- notas >= 7
notas[aprovados]   # aprovados
    Ana   Bruno Daniela 
    7.5     8.0     9.0
Código 
notas[!aprovados]  # reprovados
 Carlos Eduardo 
    6.5     5.5

3.3 Subconjuntos com subset()

A função subset() filtra linhas e seleciona colunas de um data frame com base em condições lógicas:

Código 
# Alunos com nota >= 7 em matemática
subset(dados, matematica >= 7)
    aluno matematica estatistica programacao
1     Ana        7.5         8.0         7.0
2   Bruno        8.0         7.5         8.5
4 Daniela        9.0         9.5         9.0
Código 
# Condição múltipla
subset(dados, matematica >= 7 & estatistica >= 7)
    aluno matematica estatistica programacao
1     Ana        7.5         8.0         7.0
2   Bruno        8.0         7.5         8.5
4 Daniela        9.0         9.5         9.0

3.4 Família apply()

As funções da família apply aplicam uma função a margens de matrizes ou listas, evitando laços explícitos:

  • apply(): aplica uma função nas linhas (margem 1) ou colunas (margem 2) de uma matriz ou data frame
  • lapply(): aplica uma função a cada elemento de uma lista e retorna uma lista
  • sapply(): semelhante ao lapply(), mas simplifica o resultado para vetor ou matriz quando possível
Código 
# Média por aluno (linhas)
apply(dados[, 2:4], 1, mean)
[1] 7.500000 8.000000 6.500000 9.166667 5.500000
Código 
# Média por disciplina (colunas)
apply(dados[, 2:4], 2, mean)
 matematica estatistica programacao 
        7.3         7.4         7.3
Código 
# sapply simplifica o resultado
sapply(dados[, 2:4], mean)
 matematica estatistica programacao 
        7.3         7.4         7.3

3.5 ifelse()

A função ifelse() é a versão vetorizada do if, aplicando uma condição elemento a elemento:

Código 
dados$media <- apply(dados[, 2:4], 1, mean)
dados$situacao <- ifelse(dados$media >= 7, "Aprovado", "Reprovado")
dados
    aluno matematica estatistica programacao    media  situacao
1     Ana        7.5         8.0         7.0 7.500000  Aprovado
2   Bruno        8.0         7.5         8.5 8.000000  Aprovado
3  Carlos        6.5         6.0         7.0 6.500000 Reprovado
4 Daniela        9.0         9.5         9.0 9.166667  Aprovado
5 Eduardo        5.5         6.0         5.0 5.500000 Reprovado

3.6 Estruturas de controle de fluxo

As estruturas for, while e if controlam a execução do código de forma iterativa e condicional:

  • if / else: executa um bloco de código dependendo de uma condição
  • for: repete um bloco de código para cada elemento de uma sequência
  • while: repete um bloco enquanto uma condição for verdadeira
Código 
# Classificando alunos com for + if
situacao_manual <- character(nrow(dados))
for (i in 1:nrow(dados)) {
  if (dados$media[i] >= 7) {
    situacao_manual[i] <- "Aprovado"
  } else {
    situacao_manual[i] <- "Reprovado"
  }
}
situacao_manual
[1] "Aprovado"  "Aprovado"  "Reprovado" "Aprovado"  "Reprovado"
Código 
# Simulando crescimento com while
media_simulada <- 5
incremento <- 0.3
iteracoes <- 0
while (media_simulada < 7) {
  media_simulada <- media_simulada + incremento
  iteracoes <- iteracoes + 1
}
cat("Média final:", round(media_simulada, 2), "\n")
Média final: 7.1
Código 
cat("Iterações:", iteracoes, "\n")
Iterações: 7

3.7 Funções auxiliares

  • tapply(): aplica uma função a subgrupos definidos por um fator, retornando um vetor ou array
  • aggregate(): calcula estatísticas por grupo e retorna um data frame
  • with(): permite acessar colunas de um data frame sem repetir seu nome
  • within(): semelhante ao with(), mas voltado para criação e modificação de variáveis dentro do data frame
  • ave(): calcula uma função por grupo mantendo o resultado no mesmo tamanho do vetor original, útil para comparar cada observação com a média do seu grupo
  • by(): aplica uma função a subconjuntos de um data frame definidos por um fator

### Vetores

A função `c()` concatena elementos para formar um vetor. A função `names()` atribui nomes a cada posição do vetor, permitindo indexação por nome além de indexação numérica:

```{r}
notas <- c(7.5, 8.0, 6.5, 9.0, 5.5)
```

```{r}
# Alunos com nota >= 7 em matemática
subset(dados, matematica >= 7)
```

### Família `apply()`

As funções da família `apply` aplicam uma função a margens de matrizes ou listas, evitando laços explícitos:

- **`apply()`:** aplica uma função nas linhas (margem 1) ou colunas (margem 2) de uma matriz ou data frame
- **`lapply()`:** aplica uma função a cada elemento de uma lista e retorna uma lista
- **`sapply()`:** semelhante ao `lapply()`, mas simplifica o resultado para vetor ou matriz quando possível

```{r}
# Média por aluno (linhas)
apply(dados[, 2:4], 1, mean)

# Média por disciplina (colunas)
apply(dados[, 2:4], 2, mean)

# sapply simplifica o resultado
sapply(dados[, 2:4], mean)
```

### `ifelse()`

A função `ifelse()` é a versão vetorizada do `if`, aplicando uma condição elemento a elemento:

```{r}
dados$media <- apply(dados[, 2:4], 1, mean)
dados$situacao <- ifelse(dados$media >= 7, "Aprovado", "Reprovado")
dados
```

### Estruturas de controle de fluxo

As estruturas `for`, `while` e `if` controlam a execução do código de forma iterativa e condicional:

- **`if / else`:** executa um bloco de código dependendo de uma condição
- **`for`:** repete um bloco de código para cada elemento de uma sequência
- **`while`:** repete um bloco enquanto uma condição for verdadeira

```{r}
# Classificando alunos com for + if
situacao_manual <- character(nrow(dados))
for (i in 1:nrow(dados)) {
  if (dados$media[i] >= 7) {
    situacao_manual[i] <- "Aprovado"
  } else {
    situacao_manual[i] <- "Reprovado"
  }
}
situacao_manual
```

```{r}
# Simulando crescimento com while
media_simulada <- 5
incremento <- 0.3
iteracoes <- 0
while (media_simulada < 7) {
  media_simulada <- media_simulada + incremento
  iteracoes <- iteracoes + 1
}
cat("Média final:", round(media_simulada, 2), "\n")
cat("Iterações:", iteracoes, "\n")
```

### Funções auxiliares

- **`tapply()`:** aplica uma função a subgrupos definidos por um fator, retornando um vetor ou array
- **`aggregate()`:** calcula estatísticas por grupo e retorna um data frame
- **`with()`:** permite acessar colunas de um data frame sem repetir seu nome
- **`within()`:** semelhante ao `with()`, mas voltado para criação e modificação de variáveis dentro do data frame
- **`ave()`:** calcula uma função por grupo mantendo o resultado no mesmo tamanho do vetor original, útil para comparar cada observação com a média do seu grupo
- **`by()`:** aplica uma função a subconjuntos de um data frame definidos por um fator
