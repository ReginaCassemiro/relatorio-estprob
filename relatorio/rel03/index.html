1 📌 Introdução

O pacote leem (Learn Statistics with R) é um pacote desenvolvido pelo Prof. Ben Dêivide (DEFIM/CAP/UFSJ) com o objetivo de facilitar o ensino e a aplicação da estatística descritiva e inferencial no ambiente R. O pacote disponibiliza funções para tabulação de dados, construção de gráficos, cálculo de medidas de posição e dispersão, cálculo de probabilidades e realização de testes de hipóteses, com uma interface acessível para iniciantes (Batista, 2022).

2 🎯 Objetivos

2.1 Objetivo geral

Apresentar as principais funcionalidades do pacote leem para análise estatística descritiva no R.

2.2 Objetivos específicos

  • Instalar e carregar o pacote leem
  • Aplicar a função tabfreq() para tabulação de dados
  • Construir histogramas, ogivas e gráficos de pizza
  • Calcular medidas de posição e dispersão
  • Utilizar as funções de probabilidade e teste de hipóteses

3 📚 Fundamentação Teórica

O pacote leem centraliza em um único ambiente as principais ferramentas de estatística descritiva utilizadas em cursos introdutórios. Suas funções seguem uma sintaxe encadeada com o operador pipe (|>), tornando o código mais legível e organizado (Batista e Oliveira, 2022).

As principais funções do pacote são descritas a seguir.

library(leem) — carrega o pacote no ambiente R. O pacote deve ser instalado previamente com install.packages("leem").

leem() — abre a interface gráfica interativa do pacote, ainda em desenvolvimento.

new_leem() — converte um vetor de dados em um objeto da classe leem, especificando o tipo de variável:

  • variable = 1: variável qualitativa
  • variable = 2: variável quantitativa contínua

tabfreq() — gera a tabela de distribuição de frequências. O argumento k define o número de classes. A tabela inclui frequências absolutas, relativas, acumuladas e percentuais.

hist() — constrói o histograma a partir de um objeto tabulado. Os principais argumentos são:

  • freq: tipo de frequência ("a" absoluta, "r" relativa, "p" percentual)
  • bg: adiciona ou remove o fundo do gráfico
  • barcol: vetor de cores para as barras
  • xlab: rótulo do eixo x

ogive() — constrói a ogiva (curva de frequência acumulada). Os principais argumentos são:

  • bars: exibe barras de frequência acumulada
  • both: exibe as duas ogivas (crescente e decrescente)
  • barcol: cores das barras
  • lpcol: cor da linha
  • pch: tipo de ponto

insert() — insere elementos em um gráfico já construído, como a mediana ou a média. Pode ser encadeado após ogive().

piechart() — constrói o gráfico de pizza (setores) a partir da tabela de frequências.

mpos() — calcula as medidas de posição (média, mediana e moda). O argumento grouped = FALSE retorna os valores sem agrupamento.

variance() — calcula a variância dos dados tabulados.

sdev() — calcula o desvio padrão dos dados tabulados.

cv() — calcula o coeficiente de variação, expresso em percentual, que indica a variabilidade relativa dos dados em relação à média.

P() — calcula probabilidades para distribuições de probabilidade. Aceita distribuições normal, binomial, entre outras. O argumento gui = "tcltk" abre uma interface gráfica interativa.

th() — abre a interface interativa para realização de testes de hipóteses.

4 ⚙️ Metodologia

Os dados utilizados foram gerados artificialmente por meio da função rnorm(), que simula 1000 observações de uma distribuição normal com média 100 e desvio padrão 2. A semente set.seed(10) foi definida para garantir a reprodutibilidade dos resultados. Os dados foram tabulados em 7 classes e analisados com as funções do pacote leem.

Código 
library(leem)

set.seed(10)
dados <- rnorm(1000, mean = 100, sd = 2)

tab <- dados |>
  new_leem(variable = 2) |>
  tabfreq(k = 7)

tab

5.1.2 Histograma

Código 
tab |>
  hist(
    freq = "p",
    bg = FALSE,
    barcol = heat.colors(7),
    xlab = "Variável X"
  )

O histograma com frequência percentual mostra a distribuição dos dados em 7 classes. A distribuição apresenta formato aproximadamente simétrico, compatível com a distribuição normal utilizada na geração dos dados.

5.1.3 Ogiva com inserção da mediana

Código 
tab |>
  ogive(
    bars = TRUE,
    both = TRUE,
    barcol = c("blue", "yellow"),
    lpcol = "red",
    pch = 8
  ) |>
  insert(
    type = "median",
    lcol = "green",
    ptext = 0.15
  )

A ogiva exibe as curvas de frequência acumulada crescente e decrescente. A linha verde indica a posição da mediana, que corresponde ao ponto de interseção das duas curvas.

5.1.4 Gráfico de pizza

Código 
tab |>
  piechart()

Os resultados mostram que a média e a mediana dos dados gerados são próximas de 100, confirmando a simetria da distribuição. O coeficiente de variação é baixo, indicando pequena variabilidade relativa em torno da média, o que é esperado dado o desvio padrão de 2 utilizado na simulação.

6 🧠 Considerações finais

O pacote leem centraliza as principais ferramentas de estatística descritiva em um único ambiente, com sintaxe simples e compatível com o operador pipe. As funções de tabulação, gráficos e medidas estatísticas cobrem as necessidades básicas de análises introdutórias. O uso da semente set.seed() garante que os resultados sejam reprodutíveis, o que é fundamental em análises científicas.
