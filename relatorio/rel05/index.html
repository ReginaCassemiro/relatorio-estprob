1 📌 Introdução

A mortalidade infantil é um dos principais indicadores de desenvolvimento humano e qualidade de vida de uma população. Ela mede o número de óbitos de crianças menores de um ano de idade por cada mil nascidos vivos e reflete, de forma direta, as condições de saúde, saneamento, educação e acesso a serviços públicos de um território (Instituto Brasileiro de Geografia e Estatística, 2022).

No Brasil, apesar da redução significativa nas últimas décadas, as desigualdades regionais ainda são expressivas. Estados das regiões Norte e Nordeste historicamente apresentam taxas mais elevadas em comparação com os estados do Sul e Sudeste, evidenciando disparidades socioeconômicas estruturais que merecem atenção de gestores e formuladores de políticas públicas.

Este relatório apresenta uma análise visual da taxa de mortalidade infantil (TMI) nos estados brasileiros, com base em dados públicos do IBGE, utilizando os sistemas gráficos do R base e do pacote ggplot2, além de gráficos interativos com plotly e mapa temático com geobr (Pereira e Gonçalves, 2023).

3 📚 Fundamentação Teórica

A taxa de mortalidade infantil (TMI) é calculada como o número de óbitos de crianças com menos de um ano de vida para cada mil nascidos vivos. Valores abaixo de 10 são considerados baixos pela Organização Mundial da Saúde (OMS), enquanto valores acima de 20 indicam situação de risco alto (Instituto Brasileiro de Geografia e Estatística, 2022).

Os pacotes utilizados neste relatório são:

  • geobr: malhas geográficas dos estados brasileiros
  • ggplot2: sistema de gráficos baseado na gramática de gráficos
  • plotly: gráficos interativos
  • dplyr: manipulação de dados

4 ⚙️ Obtenção e Tratamento dos Dados

Os dados utilizados foram obtidos do IBGE — Síntese de Indicadores Sociais 2022 (Instituto Brasileiro de Geografia e Estatística, 2022), que disponibiliza a taxa de mortalidade infantil estimada por estado brasileiro. Os dados foram inseridos manualmente no R em formato de data frame, organizados por estado, região e classificação de risco.

Código 
library(ggplot2)
library(plotly)
library(dplyr)
library(geobr)

# Dados de TMI por estado - IBGE 2022
tmi <- data.frame(
  estado = c("Espírito Santo", "Paraná", "Santa Catarina", "Rio Grande do Sul",
             "São Paulo", "Minas Gerais", "Distrito Federal", "Rio de Janeiro",
             "Pernambuco", "Rio Grande do Norte", "Ceará", "Mato Grosso do Sul",
             "Paraíba", "Sergipe", "Goiás", "Tocantins", "Bahia",
             "Pará", "Acre", "Alagoas", "Mato Grosso", "Amazonas",
             "Piauí", "Roraima", "Maranhão", "Rondônia", "Amapá"),
  sigla = c("ES","PR","SC","RS","SP","MG","DF","RJ","PE","RN","CE","MS",
            "PB","SE","GO","TO","BA","PA","AC","AL","MT","AM","PI","RR",
            "MA","RO","AP"),
  tmi = c(5.40, 5.70, 5.99, 6.52, 6.65, 6.86, 7.68, 7.83, 8.96, 9.86,
          9.91, 10.19, 10.87, 10.97, 11.08, 11.77, 12.33, 12.35, 12.36,
          12.57, 13.06, 13.78, 14.43, 14.52, 14.78, 16.08, 20.37),
  code_state = c(32,41,42,43,35,31,53,33,26,24,23,50,25,28,52,17,29,
                 15,12,27,51,13,22,14,21,11,16),
  regiao = c("Sudeste","Sul","Sul","Sul","Sudeste","Sudeste","Centro-Oeste",
             "Sudeste","Nordeste","Nordeste","Nordeste","Centro-Oeste",
             "Nordeste","Nordeste","Centro-Oeste","Norte","Nordeste",
             "Norte","Norte","Nordeste","Centro-Oeste","Norte",
             "Nordeste","Norte","Nordeste","Norte","Norte")
)

# Criando variável de classificação de risco
tmi <- tmi |>
  mutate(
    risco = case_when(
      tmi < 10  ~ "Baixo",
      tmi < 15  ~ "Moderado",
      TRUE      ~ "Alto"
    )
  ) |>
  arrange(desc(tmi))

barplot(

5.1.2 Gráfico de Barras — ggplot2

Código 
ggplot(tmi, aes(x = reorder(sigla, -tmi), y = tmi, fill = risco)) +
  geom_col() +
  geom_hline(yintercept = 10, color = "blue", linetype = "dashed") +
  geom_hline(yintercept = 15, color = "red",  linetype = "dashed") +

                                "Moderado" = "orange",
                                "Alto" = "tomato")) +
  labs(

    subtitle = "Fonte: IBGE, Síntese de Indicadores Sociais 2022",
    x        = "Estado",
    y        = "TMI (por mil nascidos vivos)",
    fill     = "Risco"
  ) +
  theme_classic() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))

5.1.6 Gráfico Interativo — plotly

Código 
plot_ly(
  data      = tmi,
  x         = ~reorder(sigla, -tmi),
  y         = ~tmi,
  type      = "bar",
  color     = ~risco,
  colors    = c("Baixo" = "steelblue",
                "Moderado" = "orange",
                "Alto" = "tomato"),
  text      = ~paste("Estado:", estado,
                     "<br>TMI:", round(tmi, 2),
                     "<br>Região:", regiao),
  hoverinfo = "text"
) |>
  layout(
    title  = "Taxa de Mortalidade Infantil por Estado",
    xaxis  = list(title = "Estado"),
    yaxis  = list(title = "TMI (por mil nascidos vivos)")
  )

5.1.7 Mapa Temático

Código 
estados_geo <- read_state(year = 2020, showProgress = FALSE)

mapa <- estados_geo |>
  left_join(tmi, by = "code_state")

ggplot(mapa) +
  geom_sf(aes(fill = tmi), color = "white") +
  scale_fill_viridis_c(option = "plasma", name = "TMI") +
  labs(
    title    = "Mapa da Mortalidade Infantil por Estado",
    subtitle = "Fonte: IBGE, Síntese de Indicadores Sociais 2022"
  ) +
  theme_minimal()

5.2 Comparação entre Base R e ggplot2

Critério Base R ggplot2
Facilidade Simples para gráficos básicos Curva inicial maior, mas mais organizado
Personalização Múltiplos comandos separados Camadas adicionadas com +
Estética Limitada Alta qualidade visual por padrão
Flexibilidade Adequada para análises rápidas Ideal para relatórios e publicações
Integração interativa Limitada Conversão simples com ggplotly()

O Base R é mais direto para gráficos exploratórios rápidos. O ggplot2 oferece maior controle estético e facilita a produção de gráficos prontos para publicação, especialmente quando há múltiplas variáveis de agrupamento.

5.3 Interpretação dos Resultados

Os resultados mostram que:

  • Os estados da região Norte e Nordeste concentram as maiores taxas de mortalidade infantil, com destaque para Amapá (20,37), Rondônia (16,08) e Maranhão (14,78)
  • Os estados da região Sul e Sudeste apresentam as menores taxas, com Espírito Santo (5,40) e Paraná (5,70) como os melhores índices
  • A média nacional está acima de 10, indicando que ainda há espaço para melhoria nas políticas públicas de saúde materno-infantil
  • O boxplot por região evidencia maior variabilidade nas regiões Norte e Nordeste, sugerindo desigualdades intrarregionais expressivas
  • O mapa temático reforça o gradiente Norte-Sul visualmente, com concentração de altas taxas nas regiões menos desenvolvidas

As diferenças regionais refletem desigualdades no acesso a serviços de saúde, saneamento básico, escolaridade materna e renda per capita.

6 🧠 Conclusão

A análise visual da mortalidade infantil evidenciou padrões regionais expressivos que refletem as desigualdades socioeconômicas do Brasil. Os gráficos produzidos permitiram uma leitura abrangente dos dados, cada um contribuindo com uma perspectiva diferente.

O mapa temático foi o mais informativo para comunicar diferenças regionais de forma imediata. O gráfico interativo facilitou a exploração detalhada por estado. O boxplot por região foi essencial para identificar variabilidade interna de cada grupo.

O R se mostrou uma ferramenta completa para análise de dados públicos, desde a organização dos dados até a produção de visualizações de alta qualidade com ggplot2, plotly e geobr.

```{r message=FALSE, warning=FALSE, fig.width=9, fig.height=7}
    title    = "Mapa da Mortalidade Infantil por Estado",
    subtitle = "Fonte: IBGE, Síntese de Indicadores Sociais 2022"
  ) +
  theme_minimal()
```

### Comparação entre Base R e ggplot2

| Critério | Base R | ggplot2 |
|----------|--------|---------|
| Facilidade | Simples para gráficos básicos | Curva inicial maior, mas mais organizado |
| Personalização | Múltiplos comandos separados | Camadas adicionadas com `+` |
| Estética | Limitada | Alta qualidade visual por padrão |
| Flexibilidade | Adequada para análises rápidas | Ideal para relatórios e publicações |
| Integração interativa | Limitada | Conversão simples com `ggplotly()` |

O Base R é mais direto para gráficos exploratórios rápidos. O `ggplot2` oferece maior controle estético e facilita a produção de gráficos prontos para publicação, especialmente quando há múltiplas variáveis de agrupamento.

### Interpretação dos Resultados

Os resultados mostram que:

- Os estados da região **Norte e Nordeste** concentram as maiores taxas de mortalidade infantil, com destaque para Amapá (20,37), Rondônia (16,08) e Maranhão (14,78)
- Os estados da região **Sul e Sudeste** apresentam as menores taxas, com Espírito Santo (5,40) e Paraná (5,70) como os melhores índices
- A **média nacional** está acima de 10, indicando que ainda há espaço para melhoria nas políticas públicas de saúde materno-infantil
- O **boxplot por região** evidencia maior variabilidade nas regiões Norte e Nordeste, sugerindo desigualdades intrarregionais expressivas
- O **mapa temático** reforça o gradiente Norte-Sul visualmente, com concentração de altas taxas nas regiões menos desenvolvidas

As diferenças regionais refletem desigualdades no acesso a serviços de saúde, saneamento básico, escolaridade materna e renda per capita.
